# دارینو — بازارگاه اجاره کالا (پروژه درس تجارت الکترونیکی)

سایت فارسی (راست‌به‌چپ، فونت وزیر) + بک‌اند پایتون + پایگاه داده SQLite.
بک‌اند فقط از کتابخانه استاندارد پایتون استفاده می‌کند؛ **هیچ بسته‌ای نیاز به نصب ندارد.**

## ساختار پروژه
```
Darino/
├── server.py        بک‌اند: سرو سایت + API (JSON)
├── db.py            پایگاه داده SQLite: جدول‌ها و داده‌های اولیه
├── seed.json        کالاها و دسته‌بندی‌های اولیه (۹ کالای آزمایشی)
├── test_api.py      تست خودکار API
├── darino.db        پایگاه داده (بار اول اجرا خودکار ساخته می‌شود)
└── public/          فرانت‌اند
    ├── index.html
    ├── css/style.css
    ├── js/data.js   دسته‌بندی‌ها و ۸ سؤال ارزیابی
    ├── js/app.js    منطق سایت و ارتباط با API
    └── assets/logo.svg
```

## اجرا در ویندوز ۱۱
1. **نصب پایتون** (یک‌بار): از python.org نسخه ۳٫۹ یا بالاتر را نصب کنید و در نصب، گزینه **Add python.exe to PATH** را تیک بزنید.
   بررسی: در Terminal بزنید `py --version`
2. فایل زیپ را Extract کنید (کلیک راست، Extract All).
3. داخل پوشه `Darino` کلیک راست روی فضای خالی، **Open in Terminal**.
4. اجرا: `py server.py`
5. مرورگر را باز کنید: **http://localhost:8000**
6. توقف سرور: در Terminal کلید `Ctrl + C`.

> سایت را با دوبار کلیک روی index.html باز نکنید؛ برای ارتباط با بک‌اند باید از آدرس بالا باز شود.

نکته‌ها:
- تغییر پورت (PowerShell): `$env:PORT=9000; py server.py`  — (CMD): `set PORT=9000 && py server.py`
- اجرای تست‌ها: `py test_api.py` (با پایگاه داده موقت اجرا می‌شود و داده‌های شما را تغییر نمی‌دهد)
- بازگرداندن داده‌ها به حالت اولیه: سرور را متوقف و فایل `darino.db` را حذف کنید، دوباره اجرا کنید.
- دیدن محتوای پایگاه داده: برنامه رایگان **DB Browser for SQLite** و باز کردن `darino.db`.
- فونت وزیر آنلاین لود می‌شود؛ هنگام ارائه اینترنت لازم است.

## پایگاه داده (SQLite)
| جدول | شرح |
|---|---|
| users | کاربران (نام، شماره تماس یکتا، رمز عبور هش‌شده با PBKDF2 + salt) |
| sessions | توکن ورود کاربران |
| categories | دسته‌بندی‌ها (دیجیتال و عکاسی، سفر و کمپینگ، ابزار فنی) |
| items | کالاهای قابل اجاره (قیمت روزانه، شهر، صاحب کالا، امتیاز، مشخصات) |
| favorites | علاقه‌مندی‌های هر کاربر |
| rental_requests | درخواست‌های اجاره؛ وضعیت draft (در لیست) یا submitted (ثبت‌شده) |
| messages | پیام‌های کاربران به صاحب کالا |

## API
| روش و مسیر | شرح | ورود لازم |
|---|---|---|
| POST /api/auth/register ، /api/auth/login | ثبت‌نام و ورود (برمی‌گرداند token) | خیر |
| GET /api/auth/me ، POST /api/auth/logout | اطلاعات حساب، خروج | بله |
| GET /api/items?cat=&q=&sort=&fav=1 | فهرست، جست‌وجو، مرتب‌سازی | فقط برای fav |
| GET /api/items/{id} | مشخصات یک کالا | خیر |
| POST /api/items | ثبت کالای جدید برای اجاره | بله |
| POST /api/items/{id}/messages | پیام به صاحب کالا | بله |
| GET /api/favorites ، POST /api/favorites/{id} | فهرست و تغییر علاقه‌مندی | بله |
| POST /api/promo | بررسی کد تخفیف (`DARINO10`، ده درصد) | خیر |
| GET/POST /api/requests ، DELETE /api/requests/{id} | درخواست‌های اجاره | بله |
| POST /api/requests/submit | ثبت نهایی درخواست‌ها (با کد تخفیف اختیاری) | بله |

توکن در هدر `Authorization: Bearer <token>` ارسال می‌شود. همه ورودی‌ها در سرور اعتبارسنجی می‌شوند، کوئری‌ها پارامتری‌اند (در برابر SQL Injection) و متن کاربران هنگام نمایش escape می‌شود.

## محدودیت‌ها
پرداخت واقعی وجود ندارد (طبق فاز ۱ پروژه)، و برای محیط واقعی باید HTTPS، انقضای توکن و محدودیت تعداد درخواست اضافه شود.
